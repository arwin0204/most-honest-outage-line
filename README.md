A single honest status page line an AI agent writes while every server is down: plain, first person, specific about what is down, and honest about what it cannot check or does not yet know. No invented cause, no ETA.

## Run it

```sh
python3 main.py
```

Writes the entry (144 characters, one line, no trailing newline) to `/output/entry.txt`.
